# Attendance Management System

A web-based Attendance Management System developed to simplify and manage student attendance digitally.

## 📌 Project Overview

The Attendance Management System provides separate interfaces for **Teachers** and **Students**.

Teachers can manage classes, students, subjects, attendance, reports, shortage lists, grace attendance, and student absence proofs.

Students can view their attendance, check subject-wise attendance, view absent dates, and submit absence reasons with supporting proof.

## ✨ Features

### 👨‍🏫 Teacher Module

- Teacher Login
- Teacher Dashboard
- Class Management
- Student Management
- Subject Management
- Mark Attendance
- View Attendance
- Attendance Reports
- Attendance Shortage List
- Grace Attendance Management
- View and Verify Student Proofs
- Activity History

### 👨‍🎓 Student Module

- Student Login
- Student Dashboard
- View Attendance
- View Attendance Summary
- Subject-wise Attendance
- View Absent Dates
- Submit Absence Reason
- Upload Supporting Proof
- View Proof Status
- Change Password

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
